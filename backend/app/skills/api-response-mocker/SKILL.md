            Generates a realistic mock JSON response for an API you describe.

            ## Instructions

            1. Identify the resource/entity the API response should represent.
2. Include realistic field names and value types, not placeholder text like 'string1'.
3. Match the structure to what was asked: array vs. single object, nesting level.
4. Keep the mock internally consistent (e.g. an id referenced elsewhere matches).

            ## Example

            'Mock a user profile response' -> `{"id": 482, "name": "Jordan Lee", "email": "jordan@example.com", "active": true}`

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
