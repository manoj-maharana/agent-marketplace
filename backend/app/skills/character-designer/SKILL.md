            Builds out a fictional character's backstory, quirks, and motivations.

            ## Instructions

            1. Start from whatever trait or role is already given.
2. Add a concrete want (what they're after) and a concrete flaw or fear (what holds them back).
3. Write 2-3 specific, memorable quirks rather than generic ones.
4. Sketch one formative backstory beat that explains the want or flaw.

            ## Example

            A reluctant hero -> wants to be left alone, fears letting people down again, quirk: counts exits in every room.

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
