            Suggests the right chart type and axis mapping for a dataset.

            ## Instructions

            1. Identify what's being compared: values over time, parts of a whole, or categories against each other.
2. Match that to a chart type: line for trends over time, bar for category comparison, pie only for a small part-to-whole breakdown.
3. Specify which field goes on which axis.
4. Warn if the data doesn't suit any clean chart type as described.

            ## Example

            Monthly revenue over a year -> line chart, x=month, y=revenue.

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
