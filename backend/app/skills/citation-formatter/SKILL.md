            Formats references in APA, MLA, or Chicago style.

            ## Instructions

            1. Take style, author, title, year, and source.
2. Apply the punctuation/ordering rules for the requested style exactly.
3. Return the single formatted citation string.

            ## Example

            APA: `Doe, J. (2024). A Study of Things. Example Press.`

            ## Tool

            This skill is backed by `tool.py` in this folder and registered as the callable tool `citation_formatter`. Agents with this skill enabled can invoke it automatically during a conversation.
