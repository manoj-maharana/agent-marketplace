            Walks through a code snippet line by line in plain language.

            ## Instructions

            1. Read the full snippet before explaining any line.
2. Walk through it top to bottom, explaining what each meaningful line or block does.
3. Call out anything non-obvious: edge cases, side effects, why a particular approach was used.
4. Summarize the snippet's overall purpose in one sentence at the end.

            ## Example

            A recursive function -> explained line by line, ending with 'this recursively flattens a nested list.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
