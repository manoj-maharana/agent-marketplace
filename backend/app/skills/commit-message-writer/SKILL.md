            Turns a diff summary into a clean, conventional commit message.

            ## Instructions

            1. Identify the type of change: feature, fix, refactor, docs, etc.
2. Write a short imperative-mood summary line (e.g. 'Add', not 'Added').
3. Add a body explaining why the change was made, only if that context was given.
4. Keep the summary line under ~72 characters.

            ## Example

            Diff adds retry logic to a flaky call -> 'Add retry with backoff to flaky payment API call.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
