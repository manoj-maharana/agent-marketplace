            Finds a relatable analogy to help a tricky concept click.

            ## Instructions

            1. Identify the core mechanic of the concept that's proving hard to grasp.
2. Find a familiar situation that shares that exact mechanic, not just a surface similarity.
3. Walk through how the analogy maps piece-by-piece onto the real concept.
4. Note where the analogy breaks down, so it isn't taken too literally.

            ## Example

            Explaining recursion -> 'like a Russian nesting doll: each doll contains a smaller version of the same problem.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
