            Returns the current UTC date, time, and weekday.

            ## Instructions

            1. Read the current UTC time.
2. Format it as ISO, plain date, plain time, and weekday name.

            ## Example

            -> `2026-08-12T09:41:00+00:00`, date `2026-08-12`, weekday `Wednesday`.

            ## Tool

            This skill is backed by `tool.py` in this folder and registered as the callable tool `current_datetime`. Agents with this skill enabled can invoke it automatically during a conversation.
