            Suggests which metrics belong together on a dashboard, and how to lay it out.

            ## Instructions

            1. Group metrics that answer the same underlying question together.
2. Put the single most important metric top-left, since that's read first.
3. Order remaining sections from most to least frequently checked.
4. Recommend chart type per metric based on what it's showing (trend, comparison, breakdown).

            ## Example

            Top-left: revenue trend line. Top-right: this month's total. Below: breakdown by channel.
