            Spots duplicates, nulls, and inconsistent formatting in tabular data.

            ## Instructions

            1. Scan for exact and near-duplicate rows.
2. Flag missing/null values by column.
3. Flag inconsistent formatting for the same field (e.g. 'NY' vs 'New York').
4. List the issues found rather than silently guessing a fix.

            ## Example

            'State' column mixes 'CA' and 'California' -> flagged as an inconsistency to standardize.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
