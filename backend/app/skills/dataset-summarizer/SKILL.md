            Writes a plain-English summary of what a dataset contains and shows.

            ## Instructions

            1. State what the dataset contains: number of rows, and what each row represents.
2. List the key columns and what each one measures.
3. Note the overall shape or pattern if it's obvious from what's given.
4. Keep it to plain language - no invented statistics beyond what's in the data.

            ## Example

            1,200 rows of order data, one row per order, columns: date, item, amount, region.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
