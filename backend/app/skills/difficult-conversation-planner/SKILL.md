            Helps plan how to open and navigate a tricky conversation.

            ## Instructions

            1. Clarify the core issue and the outcome the user actually wants from the conversation.
2. Draft a calm, specific opening line that names the issue without accusation.
3. Anticipate the other person's likely reaction and prepare one response to it.
4. End with a suggested close that confirms next steps.

            ## Example

            Issue: a teammate keeps missing deadlines -> opener: 'I want to check in about the last couple of deadlines...'

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
