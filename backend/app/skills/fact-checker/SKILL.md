            Cross-checks a claim against reasoning and flags shaky evidence.

            ## Instructions

            1. Restate the claim precisely so there's no ambiguity about what's being checked.
2. Reason through what would have to be true for the claim to hold.
3. Note the strength of the claim's own internal logic and any obvious gaps or unsupported leaps.
4. State a confidence level plainly rather than a flat true/false - reasoning alone can't verify facts beyond training knowledge.

            ## Example

            Claim: 'This supplement cures the common cold in 24 hours' -> flagged: no such cure is medically established; treat as unverified.

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
