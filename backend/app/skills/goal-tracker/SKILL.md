            Breaks a long-term goal into milestones with rough target dates.

            ## Instructions

            1. Clarify the long-term goal and its deadline if one exists.
2. Break it into 3-6 milestones that build toward it in order.
3. Assign each milestone a rough target date by dividing the timeline sensibly.
4. Note what 'done' looks like for each milestone.

            ## Example

            Goal: Run a 10K in 12 weeks -> Week 4: run 5K nonstop, Week 8: run 8K, Week 12: race day.
