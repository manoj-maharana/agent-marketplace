            Expands a rough idea into a detailed image-generation prompt.

            ## Instructions

            1. Identify the subject, setting, and mood in the rough idea.
2. Add concrete visual detail: lighting, color palette, composition, style reference.
3. Keep the added detail consistent with the original idea rather than replacing it.
4. Output one clean, ready-to-use prompt string.

            ## Example

            'a cat in space' -> 'a fluffy orange cat floating in a starlit nebula, soft rim lighting, digital painting style, vibrant purples and teals.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
