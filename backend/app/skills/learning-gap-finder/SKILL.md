            Asks a few questions to spot which parts of a topic you're shakiest on.

            ## Instructions

            1. Ask a few targeted questions that probe different sub-parts of the topic.
2. Note which answers were confident and correct vs. hesitant or wrong.
3. Identify the specific sub-topic behind any weak answers, not just 'this topic in general.'
4. Suggest what to review first based on the gaps found.

            ## Example

            Topic: fractions -> strong on adding, shaky on converting mixed numbers - recommend reviewing that first.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
