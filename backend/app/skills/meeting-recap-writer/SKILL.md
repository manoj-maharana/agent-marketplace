            Turns rough meeting notes into a short recap message to send to the team.

            ## Instructions

            1. Pull out what was decided, what's still open, and who owns what from the notes.
2. Write it as a short message, not a formal report - 3-5 sentences or a tight bullet list.
3. Lead with the most important decision or outcome.
4. End with clear next steps and owners.

            ## Example

            Notes -> 'Quick recap: we're going with Option B. Sam will draft the plan by Thursday. Still deciding on budget.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
