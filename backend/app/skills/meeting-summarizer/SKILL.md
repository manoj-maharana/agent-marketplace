            Condenses raw meeting notes into decisions, owners, and follow-ups.

            ## Instructions

            1. Read through the raw notes once fully before summarizing.
2. Pull out decisions made, separate from options merely discussed.
3. List action items with an owner and, if mentioned, a due date.
4. Flag anything left unresolved as an open question.

            ## Example

            Notes -> Decisions: ship v2 by Friday. Actions: Priya to update docs (Wed). Open: pricing still undecided.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
