            Generates fresh metaphors and analogies for a concept you're explaining.

            ## Instructions

            1. Identify the core mechanic or feeling of the concept being explained.
2. Search for a familiar, everyday process that shares that same mechanic.
3. Offer 2-3 options across different domains so one is likely to land.
4. Keep each metaphor to one clear sentence.

            ## Example

            Explaining caching -> 'like keeping your most-used tools on your desk instead of in the garage.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
