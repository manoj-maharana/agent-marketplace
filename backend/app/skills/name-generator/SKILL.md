            Generates name ideas for characters, products, or projects in a given style.

            ## Instructions

            1. Identify the tone requested: serious, playful, futuristic, classic, etc.
2. Generate a batch of options that fit that tone and any constraints given.
3. Avoid names that are obviously trademarked or attached to a known, specific real product.
4. Group similar-style options together so the user can pick a direction.

            ## Example

            Futuristic product name -> 'Nexora, Vantix, Lumeon, Kaelith.'

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
