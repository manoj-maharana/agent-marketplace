            Tidies up rough, stream-of-consciousness notes into organized sections.

            ## Instructions

            1. Read the raw notes and identify the natural topics/sections within them.
2. Group related fragments under those section headers.
3. Turn sentence fragments into full, readable sentences without adding new claims.
4. Remove exact duplicates but keep the original meaning intact.

            ## Example

            Scattered notes on a project -> organized into 'Goals', 'Blockers', 'Next steps' sections.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
