            Turns a research outline into a list of open research questions to answer.

            ## Instructions

            1. Walk through each section of the outline in order.
2. For each section, ask what a skeptical reader would want proven or explained there.
3. Turn each gap into a specific, answerable research question - not a vague topic.
4. Group the questions back under their originating outline section.

            ## Example

            Outline section 'Market size' -> Question: 'What data source justifies the $2B estimate?'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
