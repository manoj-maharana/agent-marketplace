            Summarizes long documents into key findings and open questions.

            ## Instructions

            1. Read through the full document before summarizing anything.
2. Extract the core findings or conclusions in the author's own terms.
3. Separate what the document claims from what it merely raises as a question.
4. Present as: key findings, methodology notes (if relevant), open questions.

            ## Example

            40-page report -> 5 bullet findings + 2 open questions the report itself doesn't resolve.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
