            Suggests rows, columns, and aggregations for a pivot table from your data.

            ## Instructions

            1. Identify the question the pivot should answer.
2. Choose the row field (what to group by) and column field (what to break out by), if any.
3. Pick the right aggregation: sum for totals, average for typical values, count for frequency.
4. State the plan as: Rows / Columns / Values / Aggregation.

            ## Example

            'Sales by region and month' -> Rows: region, Columns: month, Values: sales amount, Aggregation: sum.

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
