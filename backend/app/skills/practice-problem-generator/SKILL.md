            Generates extra practice problems similar to one you provide.

            ## Instructions

            1. Identify the structure and difficulty of the example problem given.
2. Generate new problems with the same structure but different numbers/details.
3. Keep the difficulty consistent unless asked to scale it up or down.
4. Include the answer for each generated problem.

            ## Example

            Example: '2x + 3 = 11, solve for x' -> generated: '3x + 5 = 20, solve for x' (Answer: x=5).

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
