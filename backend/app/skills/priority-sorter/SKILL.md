            Sorts a messy task list into priority order using urgency and impact.

            ## Instructions

            1. List every task with any urgency or impact info the user gave.
2. Score each on urgency (time-sensitivity) and impact (how much it matters).
3. Sort high-urgency/high-impact first, then flag anything low/low as a candidate to drop.
4. Present the sorted list with a one-line reason per item.

            ## Example

            Fix prod bug (urgent+high impact) sorts above Reply to newsletter (low+low).

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
