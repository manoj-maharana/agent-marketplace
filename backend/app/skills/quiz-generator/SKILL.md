            Turns study material into a short multiple-choice or short-answer quiz.

            ## Instructions

            1. Pull the key facts/concepts out of the study material.
2. Write questions that test understanding, not just recall of exact wording.
3. Mix question types if useful: multiple-choice, short-answer, true/false.
4. Include the correct answer with each question, kept separate so it can be hidden if needed.

            ## Example

            Material on photosynthesis -> 'What gas do plants release during photosynthesis? A) CO2 B) Oxygen C) Nitrogen - Answer: B'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
