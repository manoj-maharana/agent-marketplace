            Explains a regression or trend result in plain, non-technical language.

            ## Instructions

            1. State what the model is predicting and from what input.
2. Translate the coefficient/slope into a plain-English 'for every +1 in X, Y changes by ~N' statement.
3. Mention the fit quality in plain terms (strong/moderate/weak relationship) if given.
4. Avoid statistical jargon unless the user used it first.

            ## Example

            Slope of 2.3 -> 'each extra hour of study is associated with about 2.3 more points on the test, on average.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
