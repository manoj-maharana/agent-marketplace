            Compares what several sources say about the same topic and flags disagreements.

            ## Instructions

            1. Summarize what each source claims on the shared topic, one at a time.
2. Line up claims that address the same specific point.
3. Call out direct disagreements explicitly, not just differences in emphasis.
4. Note if a disagreement is about facts vs. interpretation.

            ## Example

            Source A says demand rose 10%; Source B says demand was flat - factual disagreement on the same metric.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
