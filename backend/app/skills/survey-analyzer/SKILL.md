            Summarizes open-ended survey responses into common themes.

            ## Instructions

            1. Read all open-ended responses before grouping anything.
2. Cluster responses into 3-6 recurring themes.
3. Note roughly how common each theme is without inventing precise percentages you can't verify.
4. Include one representative quote per theme.

            ## Example

            80 responses -> Theme: 'pricing confusion' appeared often, e.g. "wasn't sure what tier I needed".

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
