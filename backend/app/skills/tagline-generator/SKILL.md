            Generates punchy taglines and slogans for a product or campaign.

            ## Instructions

            1. Identify the single strongest benefit or feeling the product/campaign should convey.
2. Generate several short variations (under ~8 words each) built around that core idea.
3. Vary the angle across options: benefit-led, emotion-led, and playful.
4. Avoid generic phrasing that could apply to any product.

            ## Example

            Product: a fast note-taking app -> 'Think it. Type it. Done.'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
