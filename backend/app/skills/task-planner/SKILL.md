            Breaks a goal down into an ordered checklist of concrete next actions.

            ## Instructions

            1. Ask for the end goal if it isn't already clear.
2. Break it into an ordered sequence of concrete, independently-doable steps.
3. Keep each step to one action - split anything that bundles two decisions.
4. Number the steps and note any step that depends on another finishing first.

            ## Example

            Goal: Launch a personal blog -> 1) Pick a platform, 2) Register a domain, 3) Draft 3 launch posts, 4) Set up analytics, 5) Publish and share.
