            Turns a task list into a suggested time-blocked schedule for the day.

            ## Instructions

            1. Take the task list and any known durations or deadlines.
2. Estimate a duration for tasks that don't have one.
3. Lay tasks into blocks across the available hours, grouping similar work together.
4. Leave a buffer block between heavy tasks.

            ## Example

            9:00-10:30 Deep work: report draft -> 10:30-10:45 Break -> 10:45-11:30 Emails.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
