            Flags whether a message reads as too blunt, too soft, or ambiguous before you send it.

            ## Instructions

            1. Read the message as a first-time recipient would, without the sender's intended tone in mind.
2. Note whether it reads as blunt, soft, neutral, or ambiguous.
3. Point to the specific phrase driving that impression.
4. Suggest one small rewording if the tone seems likely to land wrong.

            ## Example

            'Fix this now.' -> reads as blunt/urgent; consider 'Could you take a look at this when you get a chance?'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
