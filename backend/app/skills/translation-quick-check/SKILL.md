            Gives a fast plain-language translation of a short phrase or sentence.

            ## Instructions

            1. Give a plain, direct translation of the phrase first.
2. Note if the phrase has an idiomatic meaning that a literal translation would miss.
3. Flag words with no exact equivalent and explain the closest meaning instead.
4. Keep it to a short phrase-level check, not a full document translation.

            ## Example

            'break a leg' -> not literal; means 'good luck' in an informal, theatrical context.

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
