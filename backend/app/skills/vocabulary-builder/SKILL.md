            Suggests related vocabulary and example sentences around a topic.

            ## Instructions

            1. Identify the topic or theme to build vocabulary around.
2. List related words grouped by how closely they relate to the core topic.
3. Give a one-line definition and an example sentence for each word.
4. Favor words actually useful in context over obscure ones.

            ## Example

            Topic: cooking -> 'saute (v.) - to fry quickly in a little oil. "Saute the onions until golden."'

            ## Tool

            This skill has no code implementation yet. When an agent has it enabled, the instructions above are injected into the model's context as guidance to follow.
